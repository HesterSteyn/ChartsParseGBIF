# Input data (not included)

The CSV tables are not distributed with this repository. Download the GBIF
occurrence data (https://doi.org/10.15468/dl.68eusb), process it with
parseGBIF (https://github.com/ianengelbrecht/parseGBIF), and place the
resulting tables in this folder using the file names listed in the main
README ("Scripts, inputs and outputs").

Files in this folder are ignored by git, apart from this README.
